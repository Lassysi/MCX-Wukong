# MCX Wukong

[English](README.md) | 简体中文

用 MC 的剑、弓、枪械、TNT 和方块打《黑神话：悟空》。两个游戏在同一台电脑上同时运行。

当前版本：**v0.1.0-beta.1**。这是首个公开测试版，首次安装、跨章节和长按 E 跳过剧情仍需实机验收。

## 能玩什么

- 使用 MC 的移动、视角、背包和装备，保留黑神话的地图、怪物、Boss 和主线流程。
- 放置、拆除方块，搭建掩体和平台。怪物会破坏方块，累计攻击约三次后破坏。
- 普通建筑方块需要支撑，下方失去支撑后会下坠。
- 剑斧、弓弩、枪械、TNT、岩浆和伤害药水可攻击黑神话怪物；刷怪蛋可召出生物助战。
- 盾牌抵挡正面攻击，侧面和背后不受保护。MC 食物和恢复效果可以回血。
- 保留土地庙、传送、采集、开箱等原生交互，支持末影珍珠和鞘翅。
- 新存档默认跳过整个序章。后续实机 CG 可长按 E 尝试跳过，部分场景仍有兼容问题。

以上为当前机制，尚未完成所有章节、Boss 和物品的兼容测试。

## 前置要求

| 项目 | 版本 / 要求 |
|---|---|
| 系统 | Windows 64 位；目前测试环境为 Windows 11 |
| 黑神话 | Steam PC 版，当前包对应 build **21393610** |
| Minecraft | **Java 版 1.21.4**，需要自己的 Java 版账号 |
| Fabric Loader | **0.19.5**，由随包 `.mrpack` 配置 |
| Java 运行环境 | **64 位 Java 21**，在 MC 启动器里选择 |
| 黑神话加载器 | **CSharpLoader 0.1.0**，需从作者原站安装 |
| 其他组件 | ReShade 6.8.0、联动组件由玩家包提供；MC 模组由启动器下载 |
| 启动器 | 能导入 `.mrpack`，下面以 Prism Launcher 为例 |

两个游戏都需要安装，并在同一台电脑上双开。暂未测出双开的最低硬件配置，单独能运行黑神话不代表双开流畅。MC 可先分配 4 GB 内存，并给黑神话和系统留出足够内存。

当前只支持本机单人使用，不支持 MC 基岩版或联机。其他 MC 和黑神话版本未验证，安装工具会在版本不符时停止安装。

## 安装

1. 到本仓库 **Releases** 下载玩家 ZIP，解压到新文件夹。
2. 安装 [CSharpLoader 0.1.0](https://www.nexusmods.com/blackmythwukong/mods/664)，放进黑神话的 `b1/Binaries/Win64`。
3. 用 [Prism Launcher](https://prismlauncher.org/) 导入随包 `.mrpack`，登录自己的 MC Java 账号。先启动到 MC 主菜单一次，让启动器下载客户端，然后正常退出。
4. 关闭两个游戏，打开 `MCX-Wukong-Setup.exe`，选择黑神话目录和 MC 实例的游戏文件夹。客户端 JAR 会尝试自动寻找，找不到时手动选择原版 MC 1.21.4 客户端 JAR。
5. 点击“安装”。不需要安装 Python、Java 开发工具或 .NET SDK。

[第一次安装的完整步骤](docs/INSTALL.zh-CN.md)包含下载内容、目录示例、Java 设置和双开方法。CSharpLoader 不随包转传；方块材质从你本机的 MC 客户端生成。

## 启动

1. 在启动器打开 MC，进入安装工具创建的 `MCX-Wukong` 世界。
2. 保持 MC 窗口运行，不要最小化，切换到黑神话窗口并开始新游戏或读档。
3. 等待联动接管，首次初始化通常需要几十秒。
4. 在 MC 聊天栏输入 `/function mcx:starter`，可领取一次基础装备。

新世界等待接管时没有地形，属于正常状态。不要把平时的 MC 生存世界用于联动。

## 按键

| 操作 | 按键 |
|---|---|
| 移动、攻击、放置、背包 | MC 原按键 |
| 采集、开箱、土地庙交互 | H |
| 黑神话地图 | F6 |
| 黑神话菜单 | Esc |
| 尝试跳过实机 CG | 长按 E |
| MC 聊天 / 指令 | T / 斜杠 |

安装器默认跳过新存档序章，包括序章战斗。安装时可取消。金蝉等剧情变身由黑神话控制。

## 卸载

关闭两个游戏，用 `MCX-Wukong-Setup.exe` 选择原来的两个目录，点击“卸载”。存档和 MC 世界会保留，第三方加载器也会保留。
