# MCX Wukong v0.3.0

## English

Download **[Players.zip](https://github.com/Lassysi/MCX-Wukong/releases/download/v0.3.0/MCX-Wukong-v0.3.0-Players.zip)** to play. Existing users: back up both saves and follow the [upgrade guide](https://github.com/Lassysi/MCX-Wukong/blob/main/docs/UPGRADE.md).

- **F8 switches to native Wukong controls** for spells and quests; press again to return to MC.
- Improved control recovery after grabs, cutscene teleports and native slides. Fixed high flight handing control back in mid-air and leaving the character stuck.
- Made large bosses easier to hit and stopped their invisible hitboxes pushing the player backwards.
- Reorganized the shrine shop: **170 base offers**, 27 guns and matching ammunition. Repairs are now a separate trade; resting no longer spends emeralds.
- Rebalanced equipment and explosives, restored durability/hunger costs, and added boat/minecart capture for ordinary enemies.
- Fixed enchanted golden apple healing, Infinity arrow consumption, unsupported blocks and pearl landing self-damage while bridged.
- Improved client-JAR detection in setup. New MC instances default to 60 FPS with tutorial hints off.

Requires **Black Myth Steam build 21393610**, **Minecraft Java 1.21.4**, Fabric **0.19.5**, Java **21**, Windows x64 and a separate [CSharpLoader 0.1.0](https://www.nexusmods.com/blackmythwukong/mods/664) install. Both games must run on the same PC.

**Public test release.** Full chapter/boss coverage is unfinished; slides, high flight, capture and F8 story sequences need more playtesting. [Known issues](https://github.com/Lassysi/MCX-Wukong/blob/main/docs/KNOWN-ISSUES.md) · [Usage and balance](https://github.com/Lassysi/MCX-Wukong/blob/main/docs/USAGE.md)

## 简体中文

游玩请下载 **[Players.zip](https://github.com/Lassysi/MCX-Wukong/releases/download/v0.3.0/MCX-Wukong-v0.3.0-Players.zip)**。旧版用户先备份两边存档，再按[升级说明](https://github.com/Lassysi/MCX-Wukong/blob/main/docs/UPGRADE.zh-CN.md)操作。

- **新增 F8 切换原生悟空控制**，方便施法和推进剧情；再次按下接回 MC。
- 改善投技、剧情传送和滑坡后的控制恢复；修复高空飞行切回黑神话、角色卡在空中的问题。
- 扩大大型 Boss 命中范围，修复隐形判定框推着玩家后退。
- 土地庙商店整理为 **170 项基础商品**，含 27 种枪械及配套弹药。维修改为主动交易，休息不再自动扣钱。
- 调整装备与爆炸伤害，恢复耐久和饥饿消耗，补全船／矿车困住普通怪物的玩法。
- 修复附魔金苹果回血、无限弓耗箭、悬空方块和联动期间珍珠落地自伤。
- 改进安装器客户端 JAR 查找；新 MC 实例默认 60 帧并关闭教程提示。

需要 **黑神话 Steam build 21393610**、**Minecraft Java 1.21.4**、Fabric **0.19.5**、Java **21**、Windows 64 位，并单独安装 [CSharpLoader 0.1.0](https://www.nexusmods.com/blackmythwukong/mods/664)。两款游戏须同机运行。
