# 从旧版升级

[English](UPGRADE.md) | 简体中文

v0.3.0 的两端组件需要一起更新。保留旧玩家包，用旧版安装器卸载，再在独立的新 MC 实例中安装新版。不要直接覆盖运行中的 DLL 或 JAR。

1. 正常保存并退出黑神话和 MC。
2. 手动备份黑神话 `b1/Saved/SaveGames` 和旧 MC 实例的 `saves/MCX-Wukong` 整个文件夹。保留旧玩家包与安装备份。
3. 打开**旧版** `MCX-Wukong-Setup.exe`，选择原黑神话目录和原 MC 实例目录，点击“卸载”。卸载保留游戏存档、MC 世界和建筑。
4. 将新版 Players ZIP 解压到新文件夹。把新版 `.mrpack` 导入为**新的 MC 实例**，不要覆盖旧实例；启动到主菜单后正常退出。
5. 要保留联动世界时，将旧实例的整个 `saves/MCX-Wukong` 文件夹复制到新实例的 `saves` 下。此时不要进入世界。目标已有同名世界时先停下并保留两份，不要合并或覆盖。
6. 运行新版安装器，选择原黑神话目录、**新 MC 实例**游戏目录和原版 MC 1.21.4 客户端 JAR。需要自选皮肤时重新选择原 PNG，点击“安装”。
7. 进入新实例中的 `MCX-Wukong` 世界，再启动黑神话并读取对应存档。确认可以继续后再决定是否保留旧实例，暂时不要删除备份。

已有合法联动世界不会重建。安装前，安装器会额外备份黑神话存档和已有联动世界到黑神话 `b1/Binaries/Win64/MCX-Wukong-backups/<安装编号>/`。备份不会自动回写或覆盖后续进度。

不要复制旧 `mods`、整套 `config` 或 `mcx-install-id.json` 到新实例。新版安装器会检查依赖版本及额外 JAR；旧模组残留可能导致安装被拒绝。

早期开发版若没有 `MCX-Wukong-install.json`，不属于公开安装器的升级路径，请先恢复干净游戏环境或向维护者反馈，不要盲目删除加载器、存档或模组文件。

如需回退，先退出两个游戏并使用新版安装器卸载，保留现有进度，再按旧版说明安装。不要直接将旧 ZIP 覆盖新版；不要将不同时间点的两个游戏存档混用。
