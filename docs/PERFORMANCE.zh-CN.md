# 性能与直播建议

[English](PERFORMANCE.md) | 简体中文

两款游戏同时渲染。MC 可从 1280×720、渲染距离 6、60 帧开始，不额外加光影，保持运行且不最小化；先分配约 4 GB，给黑神话和系统留内存。联动／采集链路使用同一独显，不要把 MC 改到核显作为未经验证的优化。

黑神话先限制 60 帧，GPU 仍持续满载时降低画质或尝试 2560×1440。这些是建议起点，不是最低配置跑分。改变窗口大小后确认镜头与 HUD 对齐。

OBS 虚拟摄像头接 B站直播姬时，先用 OBS 1920×1080 画布及输出、30 帧，直播姬也用相同输出；改画布后重新适配来源。最终推流编码在直播姬中设置，可用时选择 NVIDIA 硬件编码。停掉不用的 OBS 录像、推流、回放缓存，精简来源并关闭无关浏览器负载；实际布局必需的 Spout／合成来源需要保留。

OBS 官方建议限游戏帧率、精简场景，为合成留出 GPU： https://obsproject.com/kb/encoding-performance-troubleshooting

新实例配置关闭教程提示（`tutorialStep:none`）。已有实例可在完全退出 MC 后修改 `options.txt`。右上角“合成木板”等属于教程提示，不是成就；成就播报为另一项设置。
