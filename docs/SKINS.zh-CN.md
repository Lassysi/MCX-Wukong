# 自定义皮肤

[English](SKINS.md) | 简体中文

安装器可将同一张皮肤应用到 MC 和黑神话端的方块人物。未选择文件时使用项目自绘皮肤。

## 文件要求

- PNG 格式，尺寸为 **64×64 像素**。
- 使用 **Steve 经典四像素手臂**布局。暂不支持 Alex 三像素细手臂、旧版 64×32 皮肤或其他尺寸。
- 导入单张皮肤 PNG，不导入皮肤预览截图、资源包 ZIP 或人物模型文件。

皮肤文件可保存在任意文件夹，无需放进 `mods`、`resourcepacks` 或黑神话目录。安装器不会自动读取 MC 账号当前使用的皮肤。

## 首次安装时导入

1. 正常退出黑神话和 MC。
2. 从完整解压的玩家包中打开 `MCX-Wukong-Setup.exe`。
3. 按[安装说明](INSTALL.zh-CN.md)选择黑神话目录、MC 实例游戏目录和原版客户端 JAR。
4. 在第四项 **Custom skin PNG / 自选皮肤 PNG** 右侧点击 **Browse / 选择**，选择皮肤 PNG。
5. 点击 **Install / 安装**，完成后按安装说明启动两个游戏。

安装器会生成黑神话端的人物外观，并同步修改本项目 MC 联动 JAR 中的皮肤，无需手动替换材质。

## 已安装后更换皮肤

1. 正常退出两个游戏，保留完整玩家包和原安装目录。
2. 打开同版本安装器，选择原来的黑神话目录和 MC 实例游戏目录。
3. 点击 **Uninstall / 卸载**。游戏存档、MC 世界和建筑会保留。
4. 重新确认安装路径和原版客户端 JAR，在第四项选择新的 PNG。
5. 点击 **Install / 安装**。完成后仍进入原来的联动世界，读取对应的黑神话存档。

恢复项目默认皮肤时，按上述步骤卸载后重装，并将第四项留空。

## 注意事项

- 本版本不支持运行时直接换肤；替换原 PNG 后也需要重新安装才能生效。
- 不要修改玩家包的 `payload/skin.png`、手动改联动 JAR 或覆盖 `steve.mesh`。安装器会校验文件，直接修改可能导致安装或卸载失败。
- MC 和黑神话端使用相同皮肤文件，但渲染方式不同，显示效果可能存在差异。
- 部分实机 CG 或剧情变身仍可能显示原角色。导入皮肤不代表这些场景已全部兼容，详见[已知问题](KNOWN-ISSUES.zh-CN.md)。
- 公开分享皮肤时，请确认拥有相应使用和再分发权限。
