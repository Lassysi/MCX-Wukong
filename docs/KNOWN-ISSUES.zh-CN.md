# 已知问题

[English](KNOWN-ISSUES.md) | 简体中文

v0.2.0 为公开测试版。编译、加载器检查和离线回归通过，不代表已完成全部实机验收。

- 部分实机 CG、采集或开箱小动画仍可能显示原角色、存在穿模；长按 E 并非所有剧情都能跳过。金蝉等剧情变身由原生流程接管。
- 章节切换、复活和复杂剧情恢复包含修复，但没有完成全章节通关验证。安装和升级前保留两个游戏的存档备份。
- 新增商店、附魔、状态效果及其组合仍需更广泛的双开验证。MC 与黑神话数值不同，效果并非原版 MC 的完全复刻。
- 牛奶、蜂蜜对原生持续状态伤害的处理是短时抑制，不保证清除原生异常或其外观。隐身尚未适配原生敌人仇恨。
- 末影珍珠、鞘翅、坠落方块和复杂碰撞场景可能存在边界问题。可破坏场景交互不支持绕过剧情门或任务机关。
- 部分第三方枪械存在模型或弹药兼容限制；商店已排除已知异常型号。
- 仅支持 README 指定的游戏版本和独立 MC 整合包。基岩版、多人及额外模组组合不在支持范围。
- 自选皮肤仅支持经典 64×64 PNG，不支持细手臂、账号皮肤自动同步或运行时换肤。
- 全新电脑首次安装、项目自绘皮肤及长时间双开仍需进一步验证，暂未提供最低硬件配置结论。

问题反馈请提供版本、章节位置、复现步骤、报错文字，以及必要的模组日志片段。不要公开账号文件、个人存档或完整内存转储。
