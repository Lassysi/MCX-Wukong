# 常见问题

[English](FAQ.md) | 简体中文

**下载哪个文件？**
Players.zip，整包解压，安装器、`.mrpack` 和 `payload` 要放在一起。Source.zip 是源码。

**MC 目录和客户端 JAR 在哪里？**
先导入 `.mrpack`，只打开 Prism 不会创建实例。在 Prism 打开该实例的 Minecraft 文件夹，选择包含 `mods` 的目录。原版 JAR 通常在 Prism 的 `libraries/com/mojang/minecraft/1.21.4/` 下，不是 `java.exe`，详见[安装](INSTALL.zh-CN.md)。

**MC 空世界里没有手和身体？**
新联动世界先用旁观模式等待。启动黑神话、读取存档，接管后切换模式；联动后仍不正常时再检查日志。

**剧情需要悟空原生技能怎么办？**
按 F8 切回悟空，正常施法，再按 F8 返回。CG／加载中会等待；悟空仍按原生规则受伤。

**为什么放不了方块？**
先检查是否处于冒险模式，用 `/gamemode survival` 返回生存。剧情门仍按原生流程处理，不能用建造工具强拆。

**怎么买弹药、修装备？**
已激活土地庙附近，主手空手或拿绿宝石右键开商店。弹药在对应枪械旁；损坏装备移入主背包后显示维修项，休息不自动维修。详见[使用说明](USAGE.zh-CN.md)。

**怎么换皮肤？**
安装器第四栏选择经典手臂 64×64 PNG。已安装时先卸载联动，保留存档，再按[换肤说明](SKINS.zh-CN.md)重装。

**支持基岩版或联机吗？**
不支持。需要指定 Java 实例和同一台 Windows 电脑上的两款游戏。

**接管没恢复，或者太卡？**
保持 MC 运行且不最小化，使用对应世界，等待剧情／加载结束。先查[已知问题](KNOWN-ISSUES.zh-CN.md)和[性能建议](PERFORMANCE.zh-CN.md)。反馈时提供版本、地点、复现步骤及相关报错，不要公开账号数据或私人存档。
