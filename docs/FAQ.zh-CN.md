# 常见问题

[English](FAQ.md) | 简体中文

**只装了一个游戏，能用吗？**

需要同时安装并运行黑神话和 Minecraft Java。

**MC 模组是否必须安装？下载包是否包含？**

必须使用随包的整合包。玩家 ZIP 内含 `.mrpack` 和本项目的联动 JAR；导入后由启动器下载其余 8 个指定版本的模组，首次安装需要联网。不支持原版 MC，也不需要玩家自行逐个寻找模组。

**我是黑神话玩家，不熟悉 MC。**

导入随包 `.mrpack`，不要自己凑模组。进入 `MCX-Wukong` 世界，再打开黑神话。装备可用 `/function mcx:starter` 领取一次；T 打开 MC 聊天栏。

**我是 MC 玩家，黑神话端装在哪里？**

Steam → 黑神话 → 管理 → 浏览本地文件。CSharpLoader 放在 `b1/Binaries/Win64`。安装工具选择游戏根目录。

**安装器说版本不符。**

不要强行替换 DLL。本版只核对了 README 所列游戏版本；其他版本需要重新验证。

**找不到原版 MC JAR。**

在启动器打开游戏文件夹或启动器的数据文件夹，寻找 `versions/1.21.4/1.21.4.jar`。部分启动器放在 `libraries/com/mojang/minecraft/1.21.4`。选择客户端，不选模组 JAR。

**只有 MC，黑神话没有接管。**

确认 MC 已进单人世界；黑神话已读档；两个窗口均未最小化；CSharpLoader 设置为 `Develop=1`、`EnableJit=1`。不要同时开启两个 MC 实例。

**怎么拿枪？**

靠近已激活土地庙，主手空手或持绿宝石右键打开商店，购买支持的枪械和对应弹药；第一章起提供完整基础系列。也可在联动后输入 `/gamemode creative`，从创造物品栏或作者提供的物品获取方式拿取，再输入 `/gamemode survival` 返回生存。具体配方见 [Modern Guns](https://modrinth.com/datapack/modern-guns)。

**能使用指令和创造模式吗？**

安装工具创建的联动世界已启用指令。接管后按 T 打开 MC 聊天栏，输入 `/gamemode creative` 切换创造模式，输入 `/gamemode survival` 返回生存，也可使用 `/give` 获取物品。剧情、变身或章节加载期间，请等待黑神话恢复正常控制后再操作。

**装备是否影响伤害和防御？**

武器和护甲属性会影响战斗表现。黑神话敌人的伤害通过联动规则换算，护甲减伤也经过调整，不能直接套用原版 MC 的数值。高等级装备可能降低前期难度。

**视频里的大圣皮肤怎么没了？**

公开包使用项目自绘皮肤。安装器第四项“自选皮肤 PNG”可选择自己的 64×64、经典四像素手臂皮肤，两端使用同一张 PNG。文件可存放在任意位置，不会自动读取 MC 账号皮肤。首次导入和安装后换肤的步骤见[自定义皮肤](SKINS.zh-CN.md)。

**原来的存档、建筑会怎样？**

安装工具新建联动世界，不覆盖已有世界。黑神话存档和已有联动世界会先备份到 `b1/Binaries/Win64/MCX-Wukong-backups`。卸载不回退进度，也不删除建筑。

**我要反馈问题。**

写明版本、发生位置、操作步骤和报错文字。不要上传账号文件、个人存档或完整崩溃转储。

**H 和 E 分别做什么？**

H 用于采集、开箱和土地庙交互。长按 E 仅用于尝试跳过实机剧情。游玩时保持黑神话窗口在前台。

**旧版如何保留存档升级？**

先备份两个游戏存档，用旧版安装器卸载，再导入新版整合包为新实例。复制旧联动世界后安装新版，不复制旧模组和安装记录。完整步骤见[升级说明](UPGRADE.zh-CN.md)。

**商店、维修和附魔怎么用？**

用 H 激活土地庙。附近主手空手或持绿宝石右键打开商店；损坏装备移入主背包后，可用商店顶部维修交易付费修复，休息不自动扣钱。主手装备、副手附魔书，再在土地庙附近右键可应用附魔。见[使用说明](USAGE.zh-CN.md)。

**为什么弓射不出来，右键也不举盾？**

确认有箭或对应弹药、弩已装填。主手持远程武器时右键优先使用武器，切换近战武器后再使用盾牌。
