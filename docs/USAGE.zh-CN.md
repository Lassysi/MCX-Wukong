# 使用说明

[English](USAGE.md) | 简体中文

先完成[安装](INSTALL.zh-CN.md)，进入专用 MCX-Wukong 世界，保持 MC 窗口运行且不最小化，再在黑神话窗口操作。需要同时运行两款游戏。

## 按键与剧情

| 操作 | 按键 |
|---|---|
| 移动、镜头、攻击、方块和物品 | MC 常规操作 |
| 背包／交换双手／聊天 | E／F／T |
| 采集、开箱、土地庙 | H |
| 黑神话地图／菜单 | F6／Esc |
| MC 与悟空原生控制切换 | F8 |
| 尝试跳过原生实时 CG | 长按 E，仅限支持的片段 |
| 联动后领取初始装备 | `/function mcx:starter`，一次 |

遇到需要安身法等原生技能的剧情，按 F8 切回悟空，正常施法，再按 F8 从当前位置接回 MC。蓝耗、冷却和任务判定均走原生流程。CG、菜单、加载、传送期间会等待；MC 死亡界面须先复活。原生接管期间 Steve 冻结、不受 MC 伤害，悟空仍会受原生伤害；保持消息中断三秒后 Steve 自动解除冻结。

原生剧情变身和必要滑坡保留原生控制，加载中不要强行接回或切换 MC 世界。飞行保留 MC 操作，但不代表能强拆剧情门。冒险模式无法普通建造，可用 `/gamemode survival` 恢复生存；创造模式为可选玩法。

## 商店、弹药和维修

用 H 激活土地庙，附近主手空手或拿绿宝石右键打开商店。第一章起有完整基础装备档位及支持的枪械系列；弹药紧邻对应枪械，并标注适配枪。弹匣和单发弹药是不同商品，请购买匹配类型。M202 仍不提供。

基础清单 170 项，按背包内容额外显示最多 12 条维修交易。穿着的防具和副手物品需要移入主背包。用绿宝石和原损坏装备换回满耐久物品，附魔保留；休息不自动花钱维修。枪械不套用原版耐久或该维修服务。

新获得的灵蕴额外生成绿宝石，不扣原生灵蕴；六章默认每颗需要 60／100／160／250／350／500 灵蕴。已有灵蕴不会一次性转换。价格见[数值说明](BALANCE.zh-CN.md)。

附近主手装备、副手附魔书右键，可应用兼容附魔；消耗书，不需要经验或铁砧。并非所有原版附魔均已适配。

## 战斗、盾牌和食物

联动伤害采用[装备曲线](BALANCE.zh-CN.md)，另计攻击冷却、暴击、附魔和目标修正；原版物品面板不显示全部联动数值。普通 MC 生物沿用正常伤害规则。

武器、工具、防具恢复原版耐久消耗。盾牌不破碎；耗尽状态仍可格挡，但承受 50% 穿透伤害，维修后恢复。饥饿按原版消耗，近战命中代理额外消耗 0.3、格挡额外消耗 1.0，再应用配置倍率。饥饿不致死，但战斗和摔落仍会伤人；“一场 Boss 战消耗较多饥饿”是平衡目标，不是每套装备均已测得的保证。

饥饿值至少 18，且 60 秒未受伤后，每四秒恢复半颗心。附魔金苹果立即满血，提供 16 点吸收生命、120 秒异常保护、抗性Ⅰ和火焰抗性；刷新不无限叠金心，到期、牛奶或死亡会解除保护。牛奶、蜂蜜的原生持续状态伤害抑制不等于清除全部黑神话异常。

无限弓保留包括药箭在内的弹药，但背包必须至少有一支箭，空背包不能发射。主手远程物品优先于副手盾牌。

## 船与矿车捕捉

在普通敌人附近放空船／矿车，范围约为代理命中框外水平四格、垂直两格；捕捉保持到玩家打破载具或怪物死亡。联动期间只有玩家伤害能破坏载具；释放后十秒再捕捉。BossBar／EliteBar 目标不可捕捉或钓回。判定改用原生血条数据，不再按血量，高血量普通怪物也可符合条件。EliteBar 对应关系和具体敌人仍需实机确认。

## 建造与移动

普通方块必须有实际底部支撑；侧面相连不算，悬空会落下。怪物约三次攻击可以破坏普通掩体。镐子和爆炸只破坏原生可破坏物，保留掉落和事件；剧情门不强拆。

联动期间珍珠落地不自伤，但仍检查碰撞和落点。长距离地面移动可接入新坐标区域，旧建筑不搬移；高空飞行保留 MC 控制，待有地面时交接。必要滑坡由悟空原生动作完成，结束站稳后恢复 MC。这些路径仍需更广泛实机验收。

## 存档与皮肤

一份黑神话存档匹配一份 MCX 世界，先保存退出黑神话，再退出 MC。不要热替换 DLL／JAR，不要拿旧世界覆盖新进度。参见[升级](UPGRADE.zh-CN.md)、[皮肤](SKINS.zh-CN.md)和[已知问题](KNOWN-ISSUES.zh-CN.md)。
